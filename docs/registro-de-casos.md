# Registro de casos dos indícios de uso de IA

Uma linha por caso conversado com um aluno a partir do painel de indícios (S42-07, ADR-08, Q-35).
Quem conversou preenche, por PR ou pedindo a quem mantém o projeto. Serve a duas coisas: o critério
3 do relatório de eficácia ([`eficacia.md`](eficacia.md)) e a revisão das faixas a cada período
([`indicios-de-ia.md`](indicios-de-ia.md), "Calibração").

**Nunca entra aqui:** nome, matrícula, login do Dikastis, e-mail, turma, código do aluno nem
qualquer coisa que identifique a pessoa. Só a lista, a faixa e os tipos de indício que o painel
mostrou, e o que a conversa concluiu. A planilha prevista antes foi descartada em 12/10/2026: este
arquivo a substitui.

## Como preencher

| Coluna | O que vai |
|---|---|
| Data | O dia da conversa (DD/MM/AAAA) |
| Período e lista | Por exemplo, 2026.2, Lista 3 |
| Faixa | A faixa do painel: baixa, média ou alta |
| Indícios | Os tipos que pesaram, como variedade, salto_de_lista, referencia; os marcadores de estilo entre parênteses |
| Conversou | Sim ou não (por exemplo, o aluno não compareceu) |
| Conclusão | Confirmado (o aluno não explicou nem modificou o código), descartado (explicou ou modificou) ou inconclusivo |
| Observação | Opcional, sem dados do aluno: por exemplo, "o aluno aprendeu dicionário num curso fora" |

Um caso descartado é tão importante quanto um confirmado: é ele que mostra se uma faixa está alta
demais.
